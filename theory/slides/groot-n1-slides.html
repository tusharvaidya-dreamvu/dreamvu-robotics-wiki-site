What is GR00T N1?

2 / 22

GR00T N1 — Core Idea

Vision-Language-Action (VLA) foundation model for humanoid robots with a dual-system design inspired by human cognitive processing (Kahneman, 2011).

System 2 — VLM (Slow Thinking)

  • Pre-trained Vision-Language Model (Eagle-2 in N1, Cosmos-Reason2 in N1.7)
  • Processes images + language instructions
  • Runs at 10 Hz on NVIDIA L40 GPU
  • Outputs vision-language token embeddings φₜ
  • Language component kept frozen during fine-tuning

System 1 — DiT (Fast Acting)

  • Diffusion Transformer (DiT) trained with flow matching
  • Generates motor actions via iterative denoising
  • Runs at 120 Hz for motor control
  • Cross-attends to VLM output tokens φₜ
  • K=4 denoising steps at inference
Both modules are Transformer-based, tightly coupled, and jointly trained end-to-end. A single set of weights handles diverse embodiments from tabletop arms to dexterous humanoids.

Architecture — Key Dimensions & Parameters

VLM (System 2) — Eagle-2 / N1

  • Base LLM: SmolLM2 (finetuned from scratch)
  • Vision encoder: SigLIP-2
  • Image input: 224 × 224 px
  • Image tokens: 64 per frame (via pixel shuffle ↓)
  • VLM params (N1-2B): 1.34B of 2.2B total
  • Feature layer used: 12th (middle) layer — faster + higher policy success vs final layer
  • Inference rate: 10 Hz on L40 GPU

DiT (System 1) — Flow Matching

  • Architecture: DiT with adaLN (Vθ)
  • Attention: Alternating cross-attn ↔ self-attn (×N blocks)
  • Action chunk: H = 16 frames
  • Denoising steps: K = 4 at inference (Euler integration)
  • Inference latency: 63.9 ms per chunk (L40, bf16)
  • Motor rate: 120 Hz (chunk interpolated)
  • Loss: Flow matching ℒ_fm = 𝔼[‖Vθ(φₜ, Aₜᵗ, qₜ) − (ε − Aₜ)‖²]
Embodiment-specific modules (State Encoder, Action Encoder, Action Decoder) are small MLPs — lightweight adapters that let one shared DiT backbone work across all robot morphologies without retraining the core.

VLM Backbone — Eagle-2 (N1.6) vs Cosmos-Reason2 (N1.7)

Eagle-2 — Used in N1 / N1.6

  • LLM: SmolLM2 (finetuned from scratch)
  • Vision: SigLIP-2 image encoder
  • Pixel shuffle: 224×224 → 64 tokens/frame
  • VLM params in N1-2B: 1.34B of 2.2B total
  • Layer used: 12th (middle) — better than final layer for downstream policy
  • General VL training: Internet-scale data

Cosmos-Reason2-2B — Used in N1.7

  • Base: Cosmos-Reason2 world foundation model
  • 2B dedicated VLM — larger than Eagle-2 in N1-2B
  • Stronger spatial + physical reasoning — trained on physics-aware world model data
  • Better understanding of 3D scenes, articulated objects, hand-object interaction
  • Vision tokens: fed to DiT via same cross-attention mechanism
The VLM backbone is the biggest architectural change between N1.6 and N1.7. Everything else (DiT blocks, flow matching, action chunk H=16, K=4 denoising) remains the same. The DiT and embodiment-specific MLPs are the parts trained/fine-tuned for GT003.

Key Innovations

What's New in GR00T N1

13 / 22

Five Key Technical Innovations

  • Latent Action Pretraining (LAPA): For action-less human videos (Ego4D, etc.), a VQ-VAE extracts latent action embeddings from consecutive frames. Encoder: current frame xₜ → latent zₜ. Decoder: zₜ + xₜ → reconstructed xₜ₊ₕ. Enables training the VLA on internet-scale video without robot labels.
  • Neural Trajectory Generation (10× augmentation): Fine-tune WAN2.1-I2V video model on 88 hrs of real robot teleoperation. Generate 827 hrs of counterfactual robot trajectories with novel language prompts. IDM or LAPA labels provide pseudo-actions for training.
  • Auxiliary Object Detection Loss: VLM must also predict the 2D bounding box of the target object (OWL-v2 annotations) during training. Loss: ℒ = ℒ_fm + ℒ_det. Improves spatial grounding without extra inference cost.
  • Middle-Layer VLM Representations: Extract features from 12th LLM layer (not final). Empirically faster inference AND higher downstream policy success rate than final-layer features.
  • DexMimicGen Simulation Scale: Few human teleoperation demos → 780K simulation trajectories (6,500 hrs equivalent) via automated segmentation, transformation, and replay. 10,000 demos per (source, target) receptacle pair in pre-training.

Training Strategy — Pre-training → Post-training

Pre-training (N1 Base)

  • Flow-matching loss on all data pyramid layers
  • VLM language tokenizer: frozen
  • VLM vision encoder: unfrozen
  • DiT: unfrozen
  • Batch size: 16,384
  • Steps: 200,000
  • LR: 1e-4, AdamW, cosine schedule
  • Hardware: 1024 H100 GPUs (NVIDIA OSMO)
  • GPU hours: ~50,000 H100

Post-training / Fine-tuning (EXP-003 GT003)

  • Start from N1.7 pretrained checkpoint
  • VLM language tokenizer: frozen
  • VLM vision encoder: unfrozen
  • DiT: unfrozen
  • Batch size: 64 (4 GPUs × 16)
  • Steps: 20,000
  • Hardware: 4× RTX PRO 6000 Blackwell (PCIe)
  • Dataset: GT003 (26,320 episodes, 132D actions)
  • Co-trained with neural trajectories 1:1
For fine-tuning only the adapter layers (state/action encoders + action decoder) + DiT: batch size up to 200. When tuning the vision encoder too: batch size up to 16. EXP-003 tunes the full model.

EXP-001 (N1.6) vs EXP-003 (N1.7) at DreamVu

EXP-001 — GR00T N1.6 Baseline

  • Model: nvidia/GR00T-N1.6-3B
  • VLM: Eagle-2 (SmolLM2 + SigLIP-2)
  • Task: Pick-and-place eval on Isaac Sim (Robobench)
  • Embodiment: BEHAVIOR_R1_PRO (Galaxea R1 Pro)
  • Dataset: demo_data/gr1.PickNPlace (5 eps, 2096 frames)
  • Goal: Zero-shot baseline before fine-tuning
  • Status: Active — establishing baseline

EXP-003 — GR00T N1.7 Fine-tuning

  • Model: nvidia/GR00T-N1.7-3B
  • VLM: Cosmos-Reason2-2B (better spatial reasoning)
  • Task: Retail manipulation (reach, grasp, navigate)
  • Embodiment: NEW_EMBODIMENT (Unitree G1)
  • Dataset: GT003 — 26,320 eps, 7.5M frames, 132D
  • Data pipeline: SABER (MediaPipe + HaMeR/HAWOR)
  • Hardware: 4× RTX PRO 6000 Blackwell (PCIe)
  • Status: Active — training in progress
Both experiments use the same dual-system DiT + VLM architecture. The upgrade from N1.6 → N1.7 swaps the VLM backbone (Eagle-2 → Cosmos-Reason2) giving the model stronger physical scene understanding for retail environments.

Limitations & Open Problems

Known Limitations (Paper)

  • Focused on short-horizon tabletop tasks — no long-horizon loco-manipulation yet
  • Synthetic neural trajectories still struggle with physics diversity (liquids, articulated objects)
  • Post-training on one embodiment can lose cross-task generalization (e.g. bimanual handover capability lost after single-arm fine-tuning)
  • Real-world data still expensive — generalization degrades on OOD objects

Open Problems for DreamVu

  • GT003 is hand-only (132D) — no body locomotion in data yet
  • NCCL P2P crash on Blackwell PCIe limits throughput vs NVLink (EXP-003)
  • MediaPipe wrist orientation gap → HaMeR/HAWOR helps but adds latency in SABER pipeline
  • Retail: shelf collision avoidance + graceful failure recovery not yet in reward
  • No loco-manipulation yet: walking + reaching shelf simultaneously
Roadmap: stronger VLM backbone (N1.7 Cosmos-Reason2) + loco-manipulation data + whole-body RL policy (motion retargeting framework) → full retail humanoid deployment on Unitree G1.

Summary

GR00T N1 — Key Takeaways

Architecture
Dual-system: Eagle-2/Cosmos VLM (10Hz) + DiT flow-matching (120Hz). H=16 chunk, K=4 denoise, embodiment MLPs adapt to any robot.
N1.6 → N1.7 Change
VLM backbone: Eagle-2 → Cosmos-Reason2-2B. Same DiT architecture, same 3B total params. Better spatial/physical reasoning.
Training Data
592.9M frames, 8,375.7 hrs. 3-layer pyramid: real robot + synthetic (DexMimicGen + neural video) + human egocentric.
Performance
76.8% real-world avg (vs 46.4% Diffusion Policy). 10× data efficiency — 10% data ≈ full-data baseline.
