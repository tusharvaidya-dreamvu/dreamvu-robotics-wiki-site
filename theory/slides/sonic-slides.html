Motivation

The Scaling Gap in Humanoid Control

2 / 21

Scaling Laws Everywhere — Except Robotics

LLMs and vision models scale predictably. Humanoid control does not — until now.

  • Prior neural controllers: a few million parameters, trained on a handful of GPUs
  • Every new skill needs bespoke reward engineering — locomotion ≠ dancing ≠ manipulation
  • Motion tracking results shown mostly on training data — no downstream task demos
  • No system unified teleoperation, video, text, and music in a single policy
Core thesis: motion-capture-supervised tracking is the scalable foundational task for humanoid control — analogous to next-token prediction for LLMs.
3 / 21

SONIC: One Policy, Six Interfaces

A single trained policy accepts all of these simultaneously — no separate training stages.

  • :joystick: Gamepad / Joystick — interactive navigation with style
  • :vr: VR headset + controllers — full-body teleoperation
  • :video: Video — zero-shot motion imitation from camera
  • :text: Text — language-commanded motion styles
  • :musical_note: Music — audio-synchronized dancing
  • :robot: VLA model (GR00T N1.5) — loco-manipulation from vision-language commands

Architecture

Universal Control Policy

5 / 21

Three Encoders → One Token Space

Inputs (pick one or more)

  • Robot motion E_r: joint positions/velocities, F_r future frames
  • Human SMPL E_h: 3D joint positions, F_h future frames
  • Hybrid E_m: sparse head + wrist keypoints + lower-body robot motion

Shared Latent (FSQ)

  • All encoders map to the same latent space
  • Finite Scalar Quantization → universal token z
  • Robot control decoder → motor commands
  • Robot motion decoder → reconstructed motion (auxiliary)
6 / 21

The 4-Term Training Loss

All four losses are needed — L_token and L_cycle are called out as critical.

  • L_PPO — standard RL loss (PPO) for motor control
  • L_recon — reconstruction across all modalities; acts as cross-embodiment retargeting when input is human SMPL
  • L_token = ||z_r − z_h||² — forces robot & human motion into the same token space
  • L_cycle = ||E_r(D_r(z_h)) − z_r||² — cycle consistency; reinforces cross-embodiment alignment
L_token + L_cycle enable zero-shot human → robot transfer without any explicit retargeting at test time.
7 / 21

Real-Time Kinematic Motion Planner

Sits above the tracking policy. Generates motion tokens in real-time from user intent.

  • Masked Token Prediction — iteratively fills motion sequence with highest-confidence tokens first (cosine masking schedule)
  • Spring-based root trajectory — critically damped spring converts gamepad input to smooth pelvis x/y + heading
  • Temporal downsampling — 4× compression via learned tokenizer keeps sequence short
  • Speed: <5 ms on laptop · 12 ms on Jetson Orin — fully onboard-deployable
  • Replanning every 100 ms or on command update
8 / 21

GENMO: Multi-Modal Motion Generation

A separate module that conditions the motion planner on text, video, or audio.

  • Temporal transformer with cross-attention from motion tokens to multi-modal condition tokens
  • Diffusion-based motion prior for generation
  • Inference modes: pure generation (text/audio), constrained (video), hybrid switching
  • Integrates with SONIC via sliding window + diffusion inpainting for low-latency transitions

Scaling Laws: Three Independent Axes

What Was Scaled

  • Dataset size: 0.4M (LaFAN) → 7.4M → 100M frames
  • Model size: 1.2M → 42M parameters
  • Compute: 8 → 32 → 128 GPUs

What Improved

  • All three axes show consistent, monotonic MPJPE improvement
  • Dataset size has the steepest marginal gain
  • 128 GPUs needed for convergence at full data scale
  • First empirical scaling law demonstrated for humanoid motor control
12 / 21

Adaptive Motion Sampling

Prevents the policy from collapsing to easy data during training.

  • Motions binned by difficulty; high-failure bins sampled more often
  • Sampling rate capped at β × average failure rate to avoid overcorrection
  • Blended with uniform distribution — automatic curriculum without manual scheduling
  • Retargeting: human SMPL → robot via GMR and PyRoki toolchains

Real-World & Downstream Results

  • 100% success across 50 diverse sim-to-real test trajectories on Unitree G1 (dance, jumps, loco-manipulation)
  • VR teleoperation (3-point: head + 2 wrists): mean wrist error 6 cm, orientation error 8.3°, latency 121.9 ms
  • GR00T N1.5 integration (apple-to-plate pick-and-place): 95% success over 20 trials after fine-tuning on 300 VR demos
  • Interactive navigation: 0–6 m/s, 360°, style variants (drunken, injured, happy, stealth)
  • Locomotive skills: squat 0.3–0.8 m height, omnidirectional crawling
16 / 21

What the Ablations Show

Scaling dimension isolation

  • Dataset size = largest marginal effect
  • Model size = consistent secondary gain
  • Compute = further enhancement
  • All three are additive and orthogonal

Loss term necessity

  • L_token — crucial for cross-embodiment learning
  • L_cycle — reinforces latent alignment consistency
  • Spring model is robust — coefficients barely matter
  • Without L_token + L_cycle, human→robot transfer breaks

Takeaways

Limitations & Why It Matters

18 / 21

Limitations

  • Safety & compliance — no formal treatment for extended real-world deployments
  • Sensor noise — noisy real-world inputs during deployment are unaddressed
  • Task generalization — 95% VLA success is proof-of-concept; richer task distributions are future work
  • Joint training — planner, tokenizer, and control policy are trained separately; gaps remain
19 / 21

Why SONIC Matters

  • First scaling law for humanoid control — data, model size, and compute all consistently improve performance
  • Universal token space — single policy, six interfaces, no per-modality training
  • L_token + L_cycle — zero-shot human-to-robot transfer without explicit retargeting
  • 100% sim-to-real — demonstrates the gap is manageable at this data scale
  • Blueprint for foundation models — same playbook as LLMs/vision applied to full-body robot control
"SONIC provides a credible blueprint for general-purpose humanoid foundation models using the same scaling playbook that worked for language and vision."
